# HTML, CSS & JavaScript Basics 🌱

A collection of foundational front-end exercises, demonstrating core web development concepts using HTML, CSS, and vanilla JavaScript.

---

## 📁 Repository Structure

Each folder contains a standalone basic project with an `index.html`, `styles.css`, and `script.js`:

## 🚀 How to Use

1. **Clone the repo:**
    ```bash
    git clone https://github.com/Surya-K-L/HTML_CSS_JS_Basics.git
    cd HTML_CSS_JS_Basics/ProjectName
    ```

2. **Open `index.html`** in your browser. No server required — just double-click to run!

---

## 💡 Core Skills Covered

- Structuring web pages with **HTML**
- Styling with **CSS** and responsive design principles
- Interactive behaviors using **JavaScript**:
  - DOM manipulation
  - Event handling and listeners
  - Dynamic content updates
- **Basic UI/UX** components: modals, forms, carousels, etc.

---

## 🎯 Learning Goals

These basic projects help you to:

- Understand how to connect **HTML**, **CSS**, and **JS** effectively  
- Use JavaScript to interact with and update the DOM  
- Learn event-driven programming in the browser  
- Practice visual and interactive UI building  
- Lay the groundwork for more advanced web development
